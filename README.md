## 👩‍💻 Acerca de mí

Full Stack Developer y Analista Técnico Funcional especializada en **integración de sistemas** y **automatización de procesos**, Técnico Superior en Desarrollo de Aplicaciones Web.

Desde 2022 trabajo en proyectos de los sectores de formación y sanidad: recojo necesidades de negocio y las convierto en requisitos e historias de usuario en Jira, integro plataformas mediante APIs REST (WooCommerce, Zoho, Moodle, Holded), automatizo informes y procesos con Python, Zoho Flow y n8n, e implanto CRM, ERP y sistemas de tickets.

Antes trabajé en docencia y en coordinación de formación: era el nexo con empresas del sector STEM para la formación de sus empleados, diseñaba cursos e-learning (eXeLearning, SCORM, H5P) y administraba Moodle. Esta trayectoria me ayuda a entender a fondo los procesos de negocio que automatizo.

Como desarrolladora trabajo con Java/Spring Boot, PHP/Laravel, Angular, React y Vue. Mis proyectos, con demo y código, están en mi [portfolio](https://portfolio-estefaniacanales.netlify.app).

## 🚀 Proyectos destacados

### Clavea — Agenda de clases para academias de formación
App web instalable en el móvil (**PWA**) en **React 19 y TypeScript** que sustituye la libreta de clases del profesorado: anotaciones con números que se rodean con un toque y tareas para el próximo día, agenda semanal y mensual, temporizador de clase con avisos y control de pagos con las reglas de la academia (alta, mes proporcional y mensualidades de 4 o 5 clases, con historial de horarios). Recordatorios por WhatsApp y email con plantillas editables y **notificaciones push** con la pantalla apagada (Web Push, Edge Function de Supabase y `pg_cron`). Cuentas y datos en **Supabase** (PostgreSQL con políticas RLS por usuario) con copia local para usarla sin conexión, formato JSON propio validado, herramienta de migración desde Excel en Node.js y 50 tests con Vitest. Personalizada para Tu Aula Musical y adaptable a cualquier asignatura.
🔗 [Ver demo](https://clavea.onrender.com) · [Ver repositorio](https://github.com/ecanalesn/clavea)

### Mapa Musical Córdoba — Web GIS de la música en la ciudad
Mapa interactivo en **Angular 20 y Leaflet** con los conservatorios, escuelas de música y salas de concierto de Córdoba en capas temáticas. Mapa base OpenStreetMap u ortofoto PNOA (WMS del IGN), búsqueda, filtro por estilo musical y fichas de cada lugar. Datos en GeoJSON extraídos de OpenStreetMap y una API REST con respaldo local; estado gestionado con signals.
🔗 [Ver demo](https://mapa-musical-cordoba.onrender.com) · [Ver repositorio](https://github.com/ecanalesn/mapa-musical-cordoba)

### SoporteSalud — Gestión de incidencias técnicas para clínicas médicas
Aplicación web en **Java 21 y Spring Boot 4** para el servicio técnico de una red de clínicas: tickets con prioridad, área clínica y estado, objetivos de SLA de respuesta y resolución, y un panel de indicadores para dirección con gráficas de Chart.js e informe mensual exportable a Excel. API REST con errores RFC 9457, 63 tests (JUnit, Mockito) con un 96 % de cobertura, integración continua con GitHub Actions y despliegue con Docker en Render.
🔗 [Ver demo](https://soportesalud.onrender.com) · [Ver repositorio](https://github.com/ecanalesn/soportesalud)

### Forma-T — Plataforma web de formación online
Plataforma de aprendizaje autodidacta con catálogo de cursos, solicitudes de matrícula por estados y vídeos de YouTube integrados, con roles de administrador y estudiante comprobados en frontend y backend. Backend en **Laravel 12** (API REST con autenticación Sanctum) y frontend en **React 19** (Vite, Tailwind CSS, Framer Motion). Proyecto final del ciclo, migrado desde PHP y JavaScript vanilla, y desplegado en Render (frontend estático y API con Docker) con base de datos PostgreSQL en Supabase.
🔗 [Ver demo](https://forma-t.onrender.com) · [Ver repositorio](https://github.com/ecanalesn/forma-t)

### Report Automation Toolkit — Automatización de informes en Python y Java
Versión anonimizada de las herramientas que uso en producción para convertir exportaciones de WooCommerce en informes de Excel con formato: ventas semanales por categoría, previsión de cobros a plazos, detección de impagos y exportación incremental de conversaciones. En **Python** (pandas, openpyxl, descargas concurrentes) y migrada a **Java 21** (Maven, Apache POI, OpenCSV, `BigDecimal`) con 56 tests en JUnit 5 y CI en Linux y Windows.
🔗 [Repositorio Python](https://github.com/ecanalesn/automation-reports) · [Repositorio Java](https://github.com/ecanalesn/automation-reports-java)

### Tu Aula Musical — Web de clases particulares de música (proyecto propio, 2018 – actualidad)
SPA en **Vue 3 y Vue Router 4** con catálogo de clases, precios y formularios de contacto y matrícula (Netlify Forms). SEO por ruta con **prerenderizado de cada página con Puppeteer**, URL canónicas, sitemap, redirecciones 301 y datos estructurados JSON-LD. Medición con **Google Tag Manager y GA4**: Consent Mode v2 con banner propio, páginas vistas virtuales y eventos de negocio documentados en un plan de medición. Gestiono además la plataforma formativa en Moodle y sus contenidos SCORM.
🔗 [Ver web](https://tuaulamusical.com) · [Ver repositorio](https://github.com/ecanalesn/tuaulamusical)
